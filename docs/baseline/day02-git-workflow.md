## What I learned

Repository:
A project folder tracked by GitHub.

Commit:
A saved checkpoint of my work.

Branch:
A separate line of work used to make changes safely.

Pull Request:
A request to merge changes into the main branch.

Push:
Sending my local commits to GitHub.
